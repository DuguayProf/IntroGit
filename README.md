# IntroGit

Toute la classe doit produire une partie du livre (fichier livre.txt) dans la branch main.

Consignes:
- Le travail se fera par équipe de 3 à 5 personnes.
- Le seul fichier du dépôt et de toutes les branches du dépôt est livre.txt.
- Chaque équipe doit se créer une branche dans laquelle elle devra produire le chapitre qui lui sera assigné. Le nom de la branche doit être chapitreX où X est le numéro du chapitre.
- Chaque membre d'une équipe est responsable pour la création de quelques paragraphes du chapitre de son équipe. Ses paragraphes doivent être créées dans une branche portant le prénom et nom du membre de l'équipe.
